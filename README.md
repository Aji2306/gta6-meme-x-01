## Quickstart & Usage

### 1. Regenerate the Meme Picture (`meme.png`)
To run the pure-JavaScript PNG generator (Node 22 standard library only, no external dependencies):
```bash
node generate.mjs
```
This draws the 1024x1024 meme image (`meme.png`) into the repo root.

### 2. Run the Entry Program (`main.ts`)
To copy `POST.json` to the output directory (required by the bounty grader):
```bash
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
