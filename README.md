A GTA VI preorder puts your wallet on Vice City Bank's five-star wanted list. The make.fun ghost is holding onto the last coin.

Run these commands with Node.js 22 from the repo root to regenerate `meme.png` and copy the existing `POST.json` into a local output directory.

```sh
node generate.mjs
MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
